# Soulful Treats Cafe

A static pink-and-white cafe website built with HTML, CSS, JavaScript, and local media files.

## Start the site

Open this file in a browser:

The main cafe page is:

`cafe/main page/soulfultreats.html`

No web server or package installation is required.

## Main pages

- `cafe/main page/soulfultreats.html`: cafe home, gallery, menu preview, reviews, reservations, and virtual-tour link.
- `cafe/main page/menu page.html`: scrollable menu gallery with live search and suggestions.
- `cafe/main page/virtual tour.html`: video tour with browser playback controls and a back button.

## Interactive features

- Horizontally scrollable photo cards on the home and menu pages.
- Menu search with live filtering and popular-search suggestions.
- Existing reviews and a `Reviewed` / `Post New` tab interface.
- Review form with selectable one-to-five-star rating.
- New reviews saved in the current browser with `localStorage`.
- Sticky home-page navigation, active-section highlighting, and smooth scrolling.
- Opening-hours status, theme switcher, countdown timer, image previews, and scroll-reveal effects.
- Reservation form confirmation after valid submission.

## Notes

- All pages use relative paths and can be opened locally.
- Reservations, login, and reviews are browser-side demonstrations; no data is sent to a server.
- Reviews and the selected theme are stored only in the current browser.
